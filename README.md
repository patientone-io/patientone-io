## 🇬🇧 English

I build tools for my homelab and everyday life on Linux. This is where I share the code.

- **[Jellyfin Checker](https://github.com/patientone-io/jellyfin-checker)** - Check your Jellyfin library while browsing Filmweb, IMDb or TMDb.
- **[DiunTap](https://github.com/patientone-io/diun-tap)** - Update Docker containers from Telegram, with release notes, healthchecks and rollback.
- **[opusbook](https://github.com/patientone-io/opusbook)** - Convert audiobooks and podcasts to Opus to save storage space.
- **[legion-nvidia-off](https://github.com/patientone-io/legion-nvidia-off)** - Power off the NVIDIA GPU on a Lenovo Legion 5 Pro (82JQ) running Linux.

The tools run on your own devices and use your own keys for integrations. No developer telemetry.

## 🇵🇱 Polski

Buduję narzędzia do swojego homelaba i codziennej pracy pod Linuksem. Tutaj udostępniam kod.

- **[Jellyfin Checker](https://github.com/patientone-io/jellyfin-checker)** - Sprawdź swoją bibliotekę Jellyfin podczas przeglądania Filmwebu, IMDb lub TMDb.
- **[DiunTap](https://github.com/patientone-io/diun-tap)** - Aktualizuj kontenery Docker z Telegrama, z changelogami, healthcheckiem i rollbackiem.
- **[opusbook](https://github.com/patientone-io/opusbook)** - Konwertuj audiobooki i podcasty do Opus, żeby zajmowały mniej miejsca.
- **[legion-nvidia-off](https://github.com/patientone-io/legion-nvidia-off)** - Odetnij zasilanie karty NVIDIA w Lenovo Legion 5 Pro (82JQ) pod Linuksem.

Narzędzia uruchamiasz u siebie, a integracje konfigurujesz własnymi kluczami. Bez telemetrii do autora.

## 🇬🇧 English

I build lightweight, local-first tools for my homelab and daily life on Linux. Every project runs on your own hardware, uses your own API keys, and includes **zero developer telemetry**.

### 🚀 Projects

| Project | Description |
| :--- | :--- |
| 🎬 **[Jellyfin Checker](https://github.com/patientone-io/jellyfin-checker)** | Browser extension ([Chrome Web Store](https://chromewebstore.google.com/detail/jellyfin-checker/llbfpbeiiidailfdcbdeilmonlikdoef) & Firefox) and userscripts that check in real time if movies, TV series, seasons, episodes, or people are in your **Jellyfin** library while browsing **Filmweb**, **IMDb**, and **TMDb** — plus a reverse **Jellyfin → Filmweb** button and 1-click Telegram requests. |
| 🐳 **[DiunTap](https://github.com/patientone-io/diun-tap)** | Interactive 1-click Docker Compose & Podman Quadlet updates from **Telegram** for [DIUN](https://github.com/crazy-max/diun), complete with expandable GitHub changelogs, post-update healthchecks, and automatic rollback. |
| 🎧 **[opusbook](https://github.com/patientone-io/opusbook)** | Fast, multi-threaded CLI audio-to-Opus converter for audiobooks and podcasts (`rich` TUI, smart mono/stereo bitrate, sidecar `cover.jpg` extraction for Audiobookshelf, ~60–75% storage savings). |
| ⚡ **[legion-nvidia-off](https://github.com/patientone-io/legion-nvidia-off)** | Early-boot ACPI SSDT override for the **Lenovo Legion 5 Pro 16ACH6H (82JQ)** on Linux that physically cuts power to the NVIDIA dGPU (`D3cold`, 0W draw, survives suspend/resume, 6–8h battery life). |
| 🌐 **[patientone-website](https://github.com/patientone-io/patientone-website)** | Source code for [patientone.uk](https://patientone.uk) — zero-dependency static HTML/CSS website with local fonts and instant PL/EN switching. |
